# Landing Xpress — Одностраничный сайт интернет-магазина

---

**Landing Xpress** — это учебный одностроничный лендинг для вымышленного интернет-магазина. Проект создан в рамках изучения современных методов верстки и закрепления навыков работы с сетками.

Основной упор в данном проекте сделан на глубокое освоение технологий **CSS Flexbox** и **CSS Grid Layout** без использования сторонних UI-фреймворков.

> :computer: **Примечание к разработке:** Данный проект и файл документации (README.md) были полностью спроектированы, написаны и протестированы в локальной рабочей среде **Visual Studio Code (VS Code)**, а не через веб-интерфейс GitHub.

## :hammer_and_wrench: Стек технологий и инструменты:

---

*   **HTML5** — семантическая разметка (использованы теги `header`, `nav`, `main`, `section`, `footer`).
*   **CSS3** — стилизация, позиционирование и работа с сетками:
    *   **CSS Grid** — применен для построения сложных крупных сеток: секции новинок (New Arrival), популярных товаров (Top Selling Products) и брендов.
    *   **CSS Flexbox** — использован для выравнивания элементов внутри компонентов: навигационной панели (шапки), карточек товаров, преимуществ (Our Speciality) и футера.
*   **Шрифты** — подключение сторонних шрифтов для соответствия дизайн-макету.

## :brain: Сложные технические решения

Наиболее сложными и интересными задачами в проекте стала реализация визуальной глубины и перекрытия элементов с помощью чистого CSS. Элементы изначально сверстаны с прицелом на **будущее оживление с помощью JavaScript**.

### 1. Тройной слайдер-галерея с полупрозрачным оверлеем
Реализована структура из трех изображений с эффектом фокуса на центральной карточке.

![Скриншот с сайта](/img/readme-1.png)

*   **Решение:** Для боковых картинок использован псевдоэлемент `::after` (оверлей) с `pointer-events: none`, чтобы затемнение не мешало кликам. Сдвиги реализованы через комбинацию `translateX()` и `scale()` на обертках, чтобы оверлей двигался синхронно с изображениями.
*   **Перспектива:**  В будущем JS будет динамически переключать классы (`img-left`, `img-center`, `img-right`) и точки (`dots`) по клику.

### 2. Веерная раскладка карт (Секция Top Selling Products)

Сложная пятикомпонентная галерея («веер» из пяти изображений девушек).

![Скриншот с сайта](/img/readme-2.png)

*   **Решение:** Отрицательные и положительные значения `translateX()` позволили красиво наслоить картинки друг на друга. Свойство `rotateY()` разворачивает крайние изображения в 3D-пространстве, усиливая иллюзию объема, а четко выверенный `z-index` (от 1 по краям до 3 в центре) управляет правильным перекрытием карт.
*   **Перспектива:** Настроен плавный `transition` с кастомной функцией плавности `cubic-bezier`. При интеграции JS анимация смены фокуса на картах при клике или скролле будет выглядеть максимально органично.
